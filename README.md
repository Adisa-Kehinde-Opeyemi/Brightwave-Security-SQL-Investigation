# Brightwave-Security-SQL-Investigation
Brightwave Logistics SQL Portfolio Project
Project Title: Insider Risk, Data Access & Phishing Response Investigation
Tools: MySQL 8.0+
Period: August 2026

1. Introduction / Project Overview
This project investigates employee access activities, data movement, phishing exposure, and security incidents at Brightwave Logistics. SQL was used to analyze security records, identify unusual activities, assess risks, and provide recommendations for improving organizational security.

3. Objectives
- Analyze employee access activities and permissions.
- Identify unusual data downloads and exports.
- Detect unauthorized and post-termination access.
- Evaluate phishing interactions and reporting.
- Assess incident resolution and SLA compliance.
- Recommend measures to strengthen data security.
3. Key Findings
The figures below are illustrative, not actual database results.
- 12,500 access records were analyzed, with 88% granted and 12% denied.
- 80.8% of access activities involved sensitive systems.
- 14.8% of activities occurred outside business hours.
- 43 clearance violations were identified, including 5 granted access attempts.
- 12 post-termination access events were recorded, with 4 granted.
- 32 employees or activities were flagged for further investigation.
- 20% of malicious email events involved user interaction.
- Finance and HR recorded the highest phishing interaction rates at 30% each.
- Only 40% of malicious emails were reported.
- 20 incidents remained unresolved, while 19 incidents breached their SLA.
  
4. Recommendations
- Review employee access permissions regularly.
- Immediately deactivate accounts after termination.
- Monitor unusual downloads, exports, and large data transfers.
- Provide targeted phishing awareness training to Finance and HR.
- Encourage prompt reporting of suspicious emails.
- Improve incident response and SLA monitoring.
- Strengthen remote access and after-hours monitoring.
- 
5. Conclusion
The investigation highlights potential weaknesses in employee access management, data security, phishing awareness, and incident response. Implementing stronger access controls, employee training, continuous monitoring, and timely incident resolution will help Brightwave Logistics reduce security risks and protect sensitive information.
